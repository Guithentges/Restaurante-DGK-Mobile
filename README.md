# 📱 DGK Restaurant App  
Aplicativo de menu digital desenvolvido com *Expo, **React Native, **Expo Router* e *Back4App (Parse Server)*.

Este projeto foi criado para demonstrar uma solução moderna e escalável para restaurantes, permitindo gerenciamento de cardápio, equipe e unidades de forma prática.
